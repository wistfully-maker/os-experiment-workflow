# 报告格式规范

本文件描述实验报告 .docx 的格式要求。

格式规则分为两部分：
- **固定规则**：不依赖模板，所有实验报告都必须遵守
- **需从模板提取**：因课程/模板而异，需要从用户提供的模板 .docx 中自动提取

---

## 一、固定规则（不依赖模板）

以下规则适用于所有实验报告，**硬编码在 Skill 中**，不需要从模板提取。

### 1.1 截图规则

| 规则项 | 要求 |
|--------|------|
| 编号格式 | `图X.Y`（X = 章节号，Y = 该章节内序号，从 1 开始） |
| 图注位置 | 图片上方（或下方，按模板习惯） |
| 图注格式 | 宋体 9pt 加粗 居中 |
| 图片对齐 | 居中 |
| 图片宽度 | 约 5.5 英寸（约 14 cm），或按模板中图片宽度 |

### 1.2 代码块规则

| 规则项 | 要求 |
|--------|------|
| 字体 | Consolas |
| 字号 | 小五（9pt） |
| 底纹 | `#F2F2F2`（浅灰色） |
| 对齐 | 左对齐 |
| 前/后间距 | 段前 0 磅，段后 0 磅（或按模板） |

### 1.3 信息表位置规则

- 信息表**必须位于文档开头**（在章节内容之前）
- 信息表之后是实验名称表（1 行×2 格），再之后是章节内容

---

## 二、需从模板提取的规则

以下规则**因模板而异**，必须在 Phase 1 通过 `scripts/extract_template_format.py` 从模板 .docx 中提取。

如果脚本无法自动提取某项，列出缺失项，**询问用户**。

### 2.1 信息表结构

| 提取项 | 说明 | 缺失时处理方式 |
|--------|------|----------------|
| 表格维度 | 几行 × 几格 | 询问用户 |
| 所有标签文本 | 如"课程名称""学生姓名""学号"等 | 询问用户每列的填写内容 |
| 标签列宽度 | 通常 1500 DXA | 从模板读取 |
| 内容列宽度 | 因模板而异 | 从模板读取 |

### 2.2 章节结构

| 提取项 | 说明 | 缺失时处理方式 |
|--------|------|----------------|
| 章节数量 | 通常有 5 章（目的/内容/步骤/结果/总结） | 询问用户 |
| 每章标题文字 | 如"一、实验目的" | 从模板读取；如模板不清晰则询问用户 |
| 章节顺序 | 章节排列顺序 | 从模板读取 |

### 2.3 格式属性

| 提取项 | 说明 | 提取方式 |
|--------|------|----------|
| 文档大标题格式 | 字体/字号/颜色/对齐/加粗 | python-docx 读取模板段落 |
| 章节标题格式 | 字体/字号/颜色/对齐/加粗 | python-docx 读取模板段落 |
| 正文段落格式 | 字体/字号 | python-docx 读取模板段落 |
| 表格列宽 | 各列宽度（DXA） | python-docx 读取表格属性 |
| 页边距 | 上/下/左/右边距（DXA） | python-docx 读取 section 属性 |
| 图片宽度 | 模板中图片的宽度（英寸或 EMU） | python-docx 读取图片尺寸 |

## 四、注意事项

1. **信息表是动态填充的**：`build_report.py` 从模板信息表中读取所有标签，用 JSON 中 `info_table` 的对应键值填充，**不要硬编码**"课程名称""学生姓名"等标签名。

2. **模板 .docx 必须是 Transitional OOXML 格式**：用 WPS 或 Word 打开 .doc 后"另存为 .docx"即可，不要保存为 Strict OOXML 格式。

3. **章节标题是段落，不是表格行**：模板的结构是"段落 + 小表格"，不是单一大表格。章节标题（"一、实验目的"等）是蓝色段落，不在表格内。

4. **截图裁剪是必须的**：从 VM 全屏截图包含大量桌面空白，必须用 `scripts/crop_screenshots.py` 裁剪到文字内容区域。

5. **代码块格式是固定规则**：无论模板是否体现，代码块必须用 Consolas 9pt + `#F2F2F2` 底纹。

6. **如果模板格式不清晰**：（如图注格式在模板中没有明确体现），询问用户具体要求，不要猜测。
