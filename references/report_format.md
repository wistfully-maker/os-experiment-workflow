# 操作系统实验报告格式规范（精简版）

## 一、文档结构

```
[信息表] 3行×11格 (院系|年级专业|姓名|学号|课程|成绩|指导教师|同组|日期)
[标题]   "河南工业大学实验报告" — 宋体三号加粗居中
[实验名称表] 1行×2格 (实验名称 | 实验X：XXXXXX)
[空白段落]
[一、实验目的] — 蓝色标题段落（非表格行！）
  内容段落...
[二、实验内容] — 蓝色标题段落
  内容段落...
[三、实验步骤] — 蓝色标题段落
  步骤小标题 → 描述 → 代码块 → 截图
[四、实验结果] — 蓝色标题段落
  结果列表...
[五、实验总结] — 蓝色标题段落
  总结文字...
```

> **⚠️ 关键：模板是"段落 + 小表格"结构，不是单一大表格。**
> 章节标题是段落（蓝色），不是表格行。内容段落直接跟在标题后面。

## 二、字体与字号

| 元素 | 字体 | 字号 | 加粗 | 对齐 |
|------|------|------|------|------|
| 文档大标题 | 宋体 | 三号(16pt) | 加粗 | 居中 |
| 章节标题(一/二/三/四/五) | 宋体 | 四号(14pt) | 加粗 | 左对齐 |
| 正文 | 宋体 | 五号(10.5pt) | 否 | 左对齐 |
| 代码/命令 | Consolas | 小五(9pt) | 否 | 左对齐 |
| 图注(图X.Y) | 宋体 | 五号(10.5pt) | 加粗 | 居中 |
| 信息表标签 | 宋体 | 五号(10.5pt) | 加粗 | 居中 |

## 三、代码块格式

- 灰色底纹 `#F2F2F2`
- 字体 Consolas 9pt
- 左侧缩进约 360 DXA (0.25cm)
- 命令前缀用 `$`（普通用户）

## 四、截图规则

- **必须真实**（VM 终端实际操作截图）
- 宽度约 5.5 英寸，居中
- 图注格式：`图X.Y  描述文字`（X=章节号, Y=章节内序号）
  - 第三章(实验步骤)→图3.1, 图3.2...
  - 第四章(实验结果)→图4.1, 图4.2...
  - 在图片下面一行，居中放置5号宋体不加粗
- 截图需裁剪（去掉桌面空白、菜单栏），只保留终端内容区域

## 五、页面设置

| 参数 | 值 |
|------|-----|
| 纸张 | A4 (210×297mm) |
| 页边距 | 上下左右 1134 DXA (≈2cm) |

## 六、关键注意事项

1. **模板 .doc 需先另存为 .docx**——必须用 Transitional 格式，不能用 Strict OOXML
2. **信息表在开头**（与 Web 课程相反）
3. **五章结构**：实验目的→内容→步骤→结果→总结（比 Web 课程多一章）
4. **章节标题是蓝色段落**，生成报告时要保留原模板这些段落，只在后面追加内容
5. 所有截图替换为**真实截图**后提交，不得使用生成/模拟的图片
